# SPEC · hs-workbench（M0 骨架版；M1 补全量并过 G1）

品牌：小汗宝 HidraPal（占位）· 化脓性汗腺炎（HS）患者工作台 · 本机优先 · 仅回顾不解读

## 病种事实边界（0 临床审核标注）
- HS：毛囊闭锁性慢性炎症性皮肤病，反复发作的疼痛性结节、脓肿、引流窦道；常见受累部位腋下/腹股沟/会阴/臀部。Hurley Ⅰ–Ⅲ 为病情轻重语境（不做自动分级）。【待核：以医生诊断为准】

## 一级信息维度（患者视角，功能线挂患者关心点；0 访谈如实）
1. 现在怎么样 —— 发作中第 N 天 / 缓解期第 N 天、距上次发作 N 天、近 90 天发作次数（首页大状态卡，唯一 demo 源）
2. 发作与缓解 —— 区间记录、部位、疼痛 0–10、引流日记（量/性状/是否就医，默认私密）
3. 用药与治疗 —— 医生用药原文留档（不判定）；抗生素以「一次疗程」为折叠单元（32 号折叠卡）；生物制剂注射按次；手术/切开引流按次
4. 化验与复查 —— 炎症指标等化验按方法/机构可比组分列；超声复查节律
5. 就诊与材料 —— 就医信息（多家医院）、复诊问题清单、资料登记（原件/派生）

## 交互与数据底线
- 无判读列（schema 禁 diagnosis/risk_level 类）；派生值读时算
- AI 候选逐项核对，拒收零副作用；agent-draft 只填不发
- 两套合成档案 A（刚确诊记录少）/ B（长期随访发作与指标都多），唯一 demo 源
- 疾病概要 DP 四段 + ？按钮双入口（36 号；breast v0.4 对齐）
