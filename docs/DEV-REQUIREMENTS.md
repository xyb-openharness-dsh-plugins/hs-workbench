## 六、红线（对齐家族夜纲）
- 患者视角红线：功能按患者信息维度组织；每条功能线挂患者原话；无一手引语如实声明 0 访谈，改写句不冒充引语。
- 非肿瘤语义：无病期/线序/预后/生存期/疗效排序；发作—缓解、受累部位、随访节律表达。

- 界面不替医生说话：紧急口径只呈现医生已确认原话。
