# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：化脓性汗腺炎（HS）患者及家属照护者；长期反复发作、面对抗生素/生物制剂疗程与手术决策的成人患者；患者组织志愿者协作使用

场景：确诊依据档案（皮肤科诊断记录、超声/切开引流记录）与误诊经历留痕；发作—缓解区间记录（Hurley 轻重仅作语境对照，不做自动分级判定）；疼痛（0–10）与引流日记；受累部位（腋下/腹股沟/臀部等）分区记录；抗生素疗程与医生用药原文留档；生物制剂注射按次记录；手术与换药按次记录；复查与超声随访节奏；复诊问题清单与就医信息整理（默认私密）

核心流程：
1. 选择本机资料目录并导入诊断/超声/手术记录
2. 核对候选信息，建立确诊依据档案与随访节律
3. 记录发作—缓解经历、疼痛引流日记与受累部位
4. 留档医生用药原文、注射与手术按次记录
5. 生成复诊准备材料

完成结果：得到来源可追溯、可核对的个人病程档案：确诊依据、发作—缓解时间线、疼痛引流趋势、用药与手术留痕、复查节奏与复诊准备材料；所有候选信息经用户核对入档，不提供诊断与治疗建议

初始布局选择：business-first
