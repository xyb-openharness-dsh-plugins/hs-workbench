# PATIENT-FLOW · hs-workbench（M0 骨架版）

> 0 患者访谈：以下流程为病种公开资料+家族模板推演，无一手引语；M1 用真实访谈校订。

P1 确诊后首次使用：选资料目录（真入口）→ 导入诊断/超声记录 → 核对候选信息入档（AI 只产候选）
P2 发作时：发作中首页提示（仅医生已确认行动计划原话）→ 记疼痛/引流 → 就医决策材料（何时联系谁=医生原话）
P3 缓解期：缓解期第 N 天回顾 → 近 90 天发作次数 → 复诊问题清单整理
P4 复诊前：汇总发作/用药/化验 → 导出（私密过滤）→ 「和 AI 讨论」整理问题清单（不代发）
P5 长期随访：注射按次记录 → 化验趋势（可比组）→ 复查超声节律提醒
